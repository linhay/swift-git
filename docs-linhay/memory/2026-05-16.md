# 2026-05-16

## SKProcessRunner 依赖解析兼容性

- 现象：宿主项目依赖 `swift-git 2.2.1` 时，`swift-git` 的 `SKProcessRunner from: "0.0.4"` 会被解析到更新的 `SKProcessRunner 0.0.21`，导致 `Sources/SwiftGit/Custom/Shell.swift` 中 `mapError(_:)` 对 `SKProcessRunError` 的 `switch` 不再 exhaustive。
- 根因：`SKProcessRunner` 在 `0.0.13`/`0.0.16` 后新增了公开 enum case（如 pipe/platform 相关错误），这是对依赖方 exhaustive switch 的源码兼容破坏；`swift-git` 自己的 `Package.resolved` 锁在 `0.0.4`，但宿主项目不会继承这个锁定。
- 处理：已在 `SKProcessRunner 0.0.22` 中把新增错误入口改为静态工厂方法，真实 enum case 集合恢复到旧版本形态；`swift-git` 本仓库 `Package.resolved` 更新到 `SKProcessRunner 0.0.22`。
- 验证：全新临时宿主包直接依赖远端 `swift-git 2.2.1`，解析到 `SKProcessRunner 0.0.22` 后 `swift build` 通过。
